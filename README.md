# MiTienda

Proyecto desarrollado como parte de las prácticas del curso utilizando
Spring Boot, Java, Thymeleaf, MySQL y Firebase.

## Contenidos desarrollados

Durante las prácticas se trabajaron los siguientes temas:

- Configuración inicial de un proyecto Spring Boot.
- Creación de entidades con JPA.
- Uso de repositorios con Spring Data JPA.
- Implementación de servicios.
- Desarrollo de controladores.
- CRUD de categorías.
- CRUD de productos.
- Integración de Firebase Storage para imágenes.
- Consultas derivadas.
- Consultas JPQL.
- Consultas SQL nativas.
- Internacionalización mediante archivos messages.properties.

## Estructura del proyecto

El proyecto utiliza una estructura organizada en capas:

- `domain`: entidades del sistema.
- `repository`: acceso a los datos.
- `service`: lógica de negocio.
- `controller`: controladores de la aplicación.
- `templates`: vistas desarrolladas con Thymeleaf.

## Comentario personal

Durante el desarrollo de las prácticas pude comprender mejor la organización
de una aplicación web utilizando Spring Boot y la separación del proyecto
en capas. También se trabajó con consultas a base de datos, almacenamiento
de imágenes y construcción de vistas dinámicas.
